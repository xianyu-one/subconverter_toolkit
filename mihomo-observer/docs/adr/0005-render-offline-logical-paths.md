# 以离线地理估计展示逻辑代理路径

Observer 的地图展示已观测的代理顺序，而非声称还原网络封包的物理路线。地图资源与 MMDB 在本地提供，节点入口、节点出口、目标位置及用户配置的起点分别保留来源和精度；缺少依据时显示未知。这样可在 Observer 与 Mihomo 分机部署且无第三方在线服务时工作，也避免把中转入口或节点名称误当成实际出口；代价是地图可能只有部分路径可定位。

历史连接及代理组候选关系按观测时间保存；旧日期的位置使用当前离线数据库及手工覆盖重新估计，并标明版本。这样可以修正过期地理信息，同时不将当前代理组成员错误套用到历史连接。候选前置节点始终区别于逐连接实际第一跳。
