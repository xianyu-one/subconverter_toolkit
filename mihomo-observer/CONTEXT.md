# Mihomo Observer

本上下文描述对一台正在使用的 Mihomo 客户端进行长期观测，并帮助识别可能需要调整订阅配置的访问问题。

## Language

**观测实例**：用户指定的一台长期运行的 Mihomo 客户端。Observer 只分析该实例的连接行为，不包含仓库其他组件启动的临时 Mihomo。

**异常证据**：历史连接中值得用户进一步检查的可观察现象，例如短时间重复连接，或同一目标的 IPv4 与 IPv6 表现差异。异常证据本身不判定订阅配置是否错误。

**错误分流**：用户结合自身访问预期与异常证据，认定某类流量采用了不合适的分流策略。Observer 不代替用户作此判断。

**疑似 IPv6 路径问题**：同一目标的 IPv6 连接表现与 IPv4 存在值得检查的差异。它不等同于已证实发生协议回退。

**采集缺口**：观测实例与 Observer 失去有效连接，或 Observer 停止运行而无法记录连接的时间段。缺口期间没有记录不表示没有访问或没有异常。

**已观测连接**：在活动连接快照中至少出现过一次的连接。短于采样间隔的连接可能未被观测到。

**短时重复连接迹象**：同一目标与代理路径在短时间内出现多条已观测连接。它不等同于请求失败或重试。

**观测目标**：已观测连接的完整主机名；缺少主机名时是目标 IP。不同子域名分别作为目标，IP 目标不被猜测为某个域名。

**问题记录**：达到展示门槛的异常证据及其历史。近期未再次出现的问题记录仍可供回顾，不代表问题已经修复。

**代理路径**：一条已观测连接使用的规则与代理链。它描述实际观测到的路由信息，不代表该路径一定是导致异常的原因。

**链路关联**：在指定目标与时间范围内，将已观测连接分别归入其完整代理路径后得到的关系。同一目标出现多个上游节点表示多条连接使用了不同路径，不表示单条连接同时经过这些节点。

**地图路径**：将已观测连接的代理顺序与可定位的地理点对应后绘出的逻辑路径。地理点由 IP 地理数据库估计，地图线条不表示实际网络封包经过的物理路线。

**观测起点**：用户在 Observer 配置中指定的设备所在国家及省或州，用于地图路径的起点。它是用户提供的区域估计，不是连接中采集的源地址。

**节点入口**：本地客户端连接某个代理节点时使用的服务器地址。中转节点的入口位置不能当作其实际出口位置。

**节点出口**：某个代理节点转发流量后对外呈现的位置；只有已知的出口 IP 或用户明确提供的区域信息才可用于地图定位，缺少依据时保持未知。

**候选前置节点**：代理组中可供底层拨号选择的节点。候选关系不证明某条已观测连接实际使用了该节点；当 Controller 未报告逐连接选择时，实际第一跳保持未知。
