# Resource Recorder Extension

本上下文描述用户在浏览网页时检查页面资源请求，并从请求目标生成可放入仓库规则列表的候选规则。

## Language

**记录会话**：用户主动开启的跨标签页资源请求观察过程。只有用户点击停止记录时，该会话才结束；导航或关闭标签页不结束整个记录。

**页面身份**：记录期间访问的顶层页面地址。仅片段标识符变化不改变页面身份；路径或查询变化表示另一页面。各页面独立保留请求记录。

**页面资源请求**：记录会话内，该标签页中的主文档、子文档或其他页面资源发起且扩展能够观察到的一次资源获取。相同 URL 的多次获取是不同请求；失败或取消的请求也属于此概念。

**请求目标**：页面资源请求 URL 中的主机名，可能是域名或 IP 地址。URL 的路径和查询参数不属于请求目标。

**实际连接 IP**：浏览器报告该请求连接到的服务器 IP 地址。它可供用户参考，不等同于 URL 中的请求目标，也不默认成为规则的匹配值。

**候选规则**：根据请求目标或用户明确选择的实际连接 IP 生成、供用户复制并自行加入规则列表的 `匹配类型,匹配值` 文本。候选规则不包含代理策略，也不表示已写入仓库。

**可生成匹配类型**：能够从请求目标或实际连接 IP 合理构造匹配值的 Mihomo 规则类型。依赖进程、入站、地理数据库等额外信息的类型不属于此范围。

**上级域名候选**：由域名请求目标逐级向上得到、供用户选择的较宽匹配值。`DOMAIN-SUFFIX` 默认仍使用完整主机名。

**目标汇总**：将记录会话中的页面资源请求按请求目标归类后的视图。请求目标可以是域名或 IP；汇总展示请求次数与可得的耗时、声明大小，不替代逐条请求记录。

**跳转链**：一次资源获取经重定向经过的一组 URL。链中的每一跳分别有请求目标，并可分别生成候选规则。

**请求耗时**：一次页面资源请求从开始到完成的时间跨度。

**声明大小**：服务器为一次页面资源请求声明的响应大小；缺少可靠声明时为未知，不等同于实际传输字节数。
