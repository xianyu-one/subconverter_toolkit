# 首次记录时申请网站访问权限

用户第一次主动开始记录时，扩展申请观察任意网站所需的网站访问权限；获准后仅在用户主动开启的记录期间观察各标签页。页面资源可来自多个第三方域名，按当前网站单独授权会让记录缺少资源且难以让用户发现缺口。此权限范围较广，因此申请时应说明用途，并在未获授权时明确显示无法完整记录。

参考：[Chrome webRequest 权限](https://developer.chrome.com/docs/extensions/reference/api/webRequest)、[Chrome 可选权限](https://developer.chrome.com/docs/extensions/reference/api/permissions)。
