# Resource Recorder

Chrome 扩展：在主动开启的记录期间观察各标签页的网页资源请求，并复制适用于仓库 `rule-list/` 的 Mihomo 匹配规则。扩展的代码、图标、测试和设计文档都在本目录中。

## 安装

需要 Chrome 153 或更高版本。在本目录运行 `make build`，然后打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，并选中 `dist/resource-recorder-extension/`。点击工具栏图标即可打开侧边栏。首次点击“开始记录”时，Chrome 会询问网站访问权限；第三方资源也需要这项权限才能被观察到。

`make package` 会同时构建并生成 `dist/resource-recorder-extension.zip`，方便复制到其他设备；在那里解压 ZIP 后，选择解压得到的 `resource-recorder-extension/` 目录加载。修改扩展代码后，重新运行 `make build`，并在扩展管理页面点击该扩展的“重新加载”。

## 使用

1. 在侧边栏点击“开始记录”，然后正常打开或切换网页。扩展持续监听各标签页，直到点击“停止记录”；导航和关闭标签页都不会停止整个记录。开始之前已经完成的请求无法补录，当前网页可刷新后捕获首次加载。
2. 在“已记录网页”中选择记录期间访问过的网页，按请求目标查看数量、最慢单次请求、耗时合计和已知声明大小合计。展开目标可以查看单次请求、完整 URL、实际连接 IP 与失败信息。
3. 选择一个候选规则并复制，或勾选多个目标后点击“复制多行规则”。域名可选择精确匹配或后缀匹配；IP 使用单地址 `IP-CIDR`。复制的文本不含策略名，例如 `DOMAIN,api.example.com`。
4. 点击“停止记录”后，结果仍可在当前浏览器会话中查看和清除。再次开始记录会保留此前的网页结果。

扩展不向外发送记录，也不会修改仓库中的规则文件。完整 URL 可能包含敏感查询参数，请在复制或分享截图前检查。

## 记录边界

扩展使用浏览器的 `webRequest` 事件。内存缓存请求、部分浏览器内部请求或缺少权限的请求可能不可见。显示的“声明大小”来自可得的响应头，不代表实际下载字节数；取不到时显示“未知”。WebSocket 只记录握手。每页最多保留最近 1,000 条请求，最多保留最近 50 个网页；超出时会提示淘汰。浏览器重启、扩展更新或重新加载会清除会话数据。

## 开发

扩展运行时不依赖 npm 包或远程资源。所附 Noto Sans Display 字体遵循 [SIL OFL 1.1](fonts/COPYRIGHT)。`make check` 检查脚本语法，`make test` 运行规则与会话模型测试，`make clean` 清除构建产物。修改图标后可用 Pillow 运行 `python3 icons/generate.py` 重建 PNG。

设计与术语见 [docs/design.md](docs/design.md) 和 [CONTEXT.md](CONTEXT.md)。
